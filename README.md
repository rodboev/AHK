# AHK

AutoHotkey.ahk contains:

- Scroll Explorer on middle mouse button drag
- Get extended attributes of window under mouse cursor
- Scroll window under mouse cursor
- Accelerated scrolling in Media Player Classic
- Sublime Text & AutoHotkey bindings for common tasks
- AutoHotkey tray tooltip whenever script reloaded
- Many works in progress



The "includes" folder contains contributions from the community.
